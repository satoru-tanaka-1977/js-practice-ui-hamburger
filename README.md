# js-practice-ui-hamburger

Web制作における王道UIパーツである「ハンバーガーメニュー」の実装練習用リポジトリです。
HTML/CSSによるレイアウトと、JavaScript（DOM操作）による動的なクラス切り替え（トグル処理）を扱っています。

## 概要
- **目的**: JavaScriptを用いた基本的なUIコンポーネントの実装力を養う
- **カテゴリー**: UI / Webコンポーネント
- **主な機能**:
  - ハンバーガーボタンのクリックによるメニューの開閉（`is-active` クラスのトグル）
  - CSS Transition を活用したスムーズなスライドインアニメーション

## 構成ファイル
- `index.html` : マークアップ（ボタン・ナビゲーション構造）
- `style.css` : スタイリングおよび開閉状態のアニメーション定義
- `script.js` : クリックイベントおよびクラス操作のロジック

## 技術要素
- JavaScript (Vanilla JS / ES6+)
  - `document.getElementById`
  - `addEventListener('click', ...)`
  - `element.classList.toggle()`
- HTML5 / CSS3 (Flexbox, Fixed positioning, CSS Transition)
